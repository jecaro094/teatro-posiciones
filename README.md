# Teatro Posiciones

Web móvil para gestionar las posiciones del elenco de una compañía de teatro amateur. Ver `AGENTS.md`.

- Despliegue (GitHub Pages + Supabase), tokens y backups: `docs/despliegue.md`.
- Esquema y funciones de la base de datos: `docs/supabase.sql`.
- Probar en local: `python3 -m http.server 8765` y abrir `http://localhost:8765/?v=<TOKEN>` (o `?k=<TOKEN>` para admin).
